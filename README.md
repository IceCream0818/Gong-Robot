# Gong-Robot
This is a music robot made to create a gong-like sound. Built for a musical robotics class at Drexel within 4 weeks.

Note: Rhythm can be programmed in the receiver code, or use the preset 120 bpm or 300 bpm in the sender code by modifying the second index of the message.

### Electrical Components
2 ESP32 Boards, 1 Solenoid, Breadboard and Basic Circuit Components

### Dependencies
ESP32 Dev Module
